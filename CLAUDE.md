# Claude Guide

Use `AGENTS.md` as the source of truth for this project.

Key reminders:

- This is a Next.js 16 App Router project.
- Run `npm run build` before handing off code changes.
- Keep OpenAI API calls server-side.
- Do not commit `.env`, `.vercel`, `.next`, or generated Prisma output.
- The active LeetCode roadmap is `Advanced Python LeetCode`, not NeetCode 150.
- Roadmap cards link to `/roadmaps/[id]` detail pages with summaries and units.
- The publish flow uses `/api/publish-draft` to generate X thread and Medium drafts from saved notes.
